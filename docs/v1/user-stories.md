# Algebrini – User Stories

This document contains user stories for all major features, aligned with the features, roadmap, and checkup. Each story is uniquely identified (ALG-XXXX) and references the relevant feature area and validation documents.

---

## Personas
- **Child**: The primary user, playing and learning algebra through games.
- **Parent**: Monitors progress, provides consent, and supports learning.
- **Teacher**: Manages groups/classes, tracks student progress, and assigns challenges.
- **Admin**: Maintains the platform, manages content, and ensures compliance.

---

## User Stories

### Multilingual & Localization (Feature 1, Roadmap Phase 1, Checkup 1)
- **ALG-0001**: As a child, I want to use the app in my preferred language so that I can understand instructions and enjoy the games.
- **ALG-0002**: As a parent, I want to switch the app language for my child so that they can learn in their native language.

### User & Account Management (Feature 2, Roadmap Phase 1,4, Checkup 2)
- **ALG-0003**: As a child, I want to create a profile with my name and avatar so that I feel the app is personalized for me.
- **ALG-0004**: As a parent, I want to create and manage multiple child profiles so that each of my children can track their own progress.
- **ALG-0005**: As a parent, I want to approve my child's account and monitor their activity so that I can ensure their safety and progress.
- **ALG-0006**: As a teacher, I want to create a class and add students so that I can track their learning and assign challenges.

### Gameplay & Content (Feature 3, Roadmap Phase 1,3, Checkup 3)
- **ALG-0007**: As a child, I want to play a variety of mini-games so that learning algebra is fun and engaging.
- **ALG-0008**: As a child, I want new games to be added regularly so that I always have something new to try.
- **ALG-0009**: As a child, I want to progress through levels of increasing difficulty so that I am always challenged at the right level.
- **ALG-0010**: As a child, I want to unlock new levels and content as I improve so that I feel rewarded for my progress.
- **ALG-0011**: As a child, I want to receive hints and help during games so that I can learn from my mistakes.

### Rewards & Motivation (Feature 4, Roadmap Phase 3, Checkup 4)
- **ALG-0012**: As a child, I want to earn badges, stars, and trophies so that I feel proud of my achievements.
- **ALG-0013**: As a child, I want to see my progress bar and achievements so that I know how far I've come.
- **ALG-0014**: As a child, I want to customize my avatar and items so that I can express myself in the app.

### Progress Tracking & Analytics (Feature 5, Roadmap Phase 4, Checkup 5)
- **ALG-0015**: As a parent, I want to view detailed reports of my child's progress so that I can support their learning.
- **ALG-0016**: As a teacher, I want to see analytics for my class so that I can identify strengths and areas for improvement.
- **ALG-0017**: As a child, I want my progress to be saved and synced across devices so that I can continue learning anywhere.

### Social & Collaborative Features (Feature 6, Roadmap Phase 4, Checkup 6)
- **ALG-0018**: As a child, I want to join group challenges with my friends or classmates so that learning is more fun and social.
- **ALG-0019**: As a teacher, I want to create group leaderboards so that I can motivate my students.
- **ALG-0020**: As a child, I want to send safe, predefined messages to friends so that I can celebrate achievements together.

### Accessibility & Inclusivity (Feature 7, Roadmap Phase 2, Checkup 7)
- **ALG-0021**: As a child with a visual impairment, I want to use text-to-speech and high-contrast modes so that I can play the games easily.
- **ALG-0022**: As a child with dyslexia, I want to use a dyslexia-friendly font so that reading is easier for me.
- **ALG-0023**: As a parent, I want to adjust font sizes and color schemes for my child so that the app is comfortable for them.

### Platform & Technical (Feature 8, Roadmap Phase 1,4, Checkup 8)
- **ALG-0024**: As a child, I want to play the app on my tablet, phone, or computer so that I can learn anywhere.
- **ALG-0025**: As a child, I want to play offline on my device so that I can learn even without internet.
- **ALG-0026**: As a parent, I want my child's data to be stored securely and privately so that I can trust the app.

### UI/UX for Kids (Feature 9, Roadmap Phase 2, Checkup 9)
- **ALG-0027**: As a child, I want the app to be colorful, playful, and easy to use so that I enjoy learning.
- **ALG-0028**: As a child, I want to see fun animations and hear sounds when I achieve something so that I feel excited to play.

### Support & Feedback (Feature 10, Roadmap Phase 4, Checkup 10)
- **ALG-0029**: As a parent, I want to access help and FAQs in the app so that I can resolve issues quickly.
- **ALG-0030**: As a user, I want to report bugs or give feedback so that the app can improve.

### Monetization (Optional/Future) (Feature 11, Roadmap Phase 5, Checkup 11)
- **ALG-0031**: As a parent, I want to access premium content for my child if I choose, but never see ads in the child experience.
- **ALG-0032**: As a teacher, I want to subscribe for advanced analytics and tools for my class.

**Note:** Each user story is mapped to one or more features in features.md and should be referenced in the roadmap and checkup documents for alignment.
