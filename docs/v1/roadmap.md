# Algebrini – Full Features Roadmap

This roadmap outlines the next phases for Algebrini, based on the comprehensive feature plan in features.md.

## Phase 1: Core Architecture & Extensibility *(Features: 1,2,3,8; ALG-0001, ALG-0003, ALG-0007, ALG-0008, ALG-0024; Checkup: 1,2,3,8)*

- [ ] Implement a central game registry for dynamic game discovery (Feature 3, ALG-0008, Checkup 3)
- [ ] Design and implement a level system for each game (with unlock logic) (Feature 3, ALG-0009, ALG-0010, Checkup 3)
