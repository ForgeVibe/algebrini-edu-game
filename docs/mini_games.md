# Mini-Games Overview

## Factorization Fun

**Description:**
- Enter all factors of the given number, separated by commas (e.g., for 6: `1,2,3,6`).
- Numbers range from easy (6, 12) to harder (31, 97).
- Hints available: "A factor is a number that divides evenly into another number."

**Gameplay:**
- Player is shown a number and must type all its factors in any order.
- The answer is correct if all and only the correct factors are entered (order and whitespace ignored).
- Progresses to the next number after a correct answer.

**Test Coverage:**
- Metadata (title, id)
- Challenge question and answer validation (true/false)
- Next/reset logic
- Hint correctness
