# Algebrini – MVP Feature Set

This document details the Minimum Viable Product (MVP) features for the first public release of Algebrini. The MVP focuses on delivering a functional, engaging, and accessible educational game for children, with essential features for learning, user management, and progress tracking.

---

## 1. Multilingual & Localization
- Full support for French and English interfaces
- All in-game text, menus, and instructions available in both languages
- Language selection at first launch and in settings
- Modular localization system for future language additions

## 2. User & Account Management
- Single child profile per device (username, avatar selection)
- Local authentication (no email required for MVP)
- Option to reset or delete profile
- Basic privacy notice and compliance (no data sharing)

## 3. Core Gameplay & Content
- Interactive mini-games for:
  - Recursive sequences (Fibonacci, arithmetic)
  - Simple equations (one variable)
- Level progression system:
  - Sequential unlocking of levels
  - Increasing difficulty
- Magical universe theme with basic story introduction
- Visual feedback for correct/incorrect answers
- Hints available for each mini-game
- In-game tutorial for first-time users

## 4. Rewards & Motivation
- Visual rewards (stars, badges) for level completion
- Progress bar for each mini-game
- Simple achievement system (e.g., "First Level Completed")

## 5. Progress Tracking
- Local saving of progress (levels completed, scores, achievements)
- Resume progress on same device
- No cloud sync in MVP

## 6. Platform & Technical
- Cross-platform support: Android, iOS, and Web
- Responsive UI for all supported devices
- Offline play supported (no internet required after install)
- Modular codebase for easy future expansion

## 7. Accessibility & Inclusivity
- Adjustable font size in settings
- Colorblind-friendly color palette
- Simple, readable fonts

## 8. Support & Feedback
- In-app help section (FAQ, how to play)
- Basic bug reporting via email link

---

This MVP feature set ensures a solid foundation for Algebrini, focusing on core educational value, accessibility, and user experience. Advanced features and enhancements will be added in future releases as outlined in features.md.
