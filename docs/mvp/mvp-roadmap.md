# Algebrini MVP Roadmap

This roadmap outlines the key phases and actionable steps to create a fully tested and functional MVP for Algebrini.

---

## 1. Technical Planning & Setup
- **Choose tech stack:** (Flutter recommended for cross-platform support)
- **Set up project repository:** Initialize with folders for screens, widgets, models, localization, etc.
- **Set up CI/CD:** (Optional) for automated builds and tests.

## 2. Design & Prototyping
- **Wireframes/UI mockups:** Design main screens (home, profile, mini-games, progress, settings).
- **Define user flows:** Map onboarding, gameplay, language switching, and progress tracking.
- **Accessibility review:** Ensure color palettes, fonts, and layouts are accessible.

## 3. Core Development
### a. Localization
- Implement language switching and translation system.
- Add all UI strings in both French and English.

### b. User Management
- Implement local profile creation (username, avatar).
- Add profile reset/delete functionality.

### c. Core Gameplay
- Develop two core mini-games (recursive sequences, simple equations).
- Implement level progression and unlocking.
- Add hints, feedback, and basic story elements.

### d. Rewards & Progress
- Visual rewards (stars, badges).
- Progress bar and achievement system.
- Local storage for progress.

### e. Accessibility
- Adjustable font size.
- Colorblind-friendly palette.

### f. Support & Help
- In-app help/FAQ.
- Bug reporting via email.

## 4. Testing
- **Unit tests:** For logic, models, and utility functions.
- **Widget/UI tests:** For main screens and interactions.
- **Manual testing:** On all target platforms (Android, iOS, Web).
- **Localization testing:** Ensure all text appears correctly in both languages.
- **Accessibility testing:** Font size, color contrast, navigation.

## 5. Polish & QA
- Refine UI/UX based on feedback.
- Fix bugs and edge cases.
- Optimize performance for all platforms.

## 6. Documentation
- Update README and add user guide if needed.
- Document code structure and how to contribute.

## 7. Release
- Prepare app store/web release builds.
- Create a launch checklist (icons, screenshots, privacy policy, etc.).
- Soft launch/beta test with a small group for feedback.

## 8. Iterate
- Gather user feedback.
- Plan for post-MVP improvements and new features.

---

This roadmap is designed to guide the team through a focused and efficient MVP development process for Algebrini.
