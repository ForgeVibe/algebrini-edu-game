# Algebrini - The Apprentice Magician

Welcome to **Algebrini**, an educational game designed to help children aged 9 to 13 learn algebra concepts while having fun!

---

## 🎯 Game Objective

Step-by-step learning of core algebra topics:  
- Recursive sequences (Fibonacci, arithmetic sequences)  
- Simple equations and inequalities  
- Factorization and algebraic expressions  
- Linear and quadratic functions  
- Mathematical logic and reasoning  
All within a magical and interactive universe.

---

## 🧙‍♂️ About the Project

This project is a Flutter prototype ensuring smooth cross-platform experience (Android, iOS, Web).  
The game interface is entirely in French to facilitate learning, while the codebase and documentation are in English for maintainability.

---

## 🚀 Main Features

- Interactive mini-games for completing sequences and solving puzzles  
- Level progression system with visual rewards  
- Magical characters and immersive atmosphere  
- Localization support for easy multilingual extension  
- Modular and well-commented code for easy contributions

---

## 📂 Project Structure

- `/lib/screens` : game screens (home, levels, mini-games)  
- `/lib/widgets` : reusable UI components  
- `/lib/models` : game state management  
- `/lib/utils` : helper functions  
- `/lib/l10n` : translation files  
- `pubspec.yaml` : dependencies (flutter_localizations, intl, etc.)

---

## 🔧 Installation & Running

1. Clone the repository:
```bash
git clone https://github.com/ForgeVibe/algebrini-edu-game.git
cd algebrini-edu-game
````

2. Install dependencies:

```bash
flutter pub get
```

3. Run on emulator or device:

```bash
flutter run
```
